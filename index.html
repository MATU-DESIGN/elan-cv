ON VOUS RÉPOND

Avant de vous lancer.

Ai-je besoin de créer un compte ?＋

Non. L’accès est direct, sans inscription ni connexion Google. Choisissez un modèle ou partez d’une page blanche. Vos CV sont conservés dans votre navigateur, sur cet appareil. Vous pouvez télécharger une sauvegarde depuis « Mes CV ».

Est-ce que je peux changer de modèle ?＋

Oui, à tout moment dans l’éditeur. Votre contenu reste en place quand vous changez de modèle, de couleur ou de police.

Comment fonctionne le paiement ?＋

Le tarif prévu est de 2 000 FCFA par CV. Le paiement Mobile Money n’est pas encore disponible. Pendant cette version d’essai, le PDF peut être téléchargé sans paiement ; aucune transaction n’est effectuée.

Où sont conservées ma photo et mes informations ?＋

Dans le stockage local de votre navigateur. Elles ne sont pas envoyées à un serveur par cette version. Effacer les données du navigateur les supprime. Pensez à exporter une sauvegarde, surtout sur un appareil partagé.
