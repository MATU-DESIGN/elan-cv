# Élan CV

Démonstration d'un créateur de CV en français pour le Burkina Faso : six modèles, création libre, photo, aperçu et export PDF A4. Accès direct, sans compte.

## Version actuelle

Les CV et photos sont conservés dans le navigateur de chaque visiteur. Ils ne sont pas envoyés à GitHub ni inclus dans ce dépôt. Les profils présentés dans la galerie sont fictifs.

Le tarif prévu est de **2 000 FCFA par CV**. Aucun paiement n'est actif : l'export de cette version d'essai est accessible gratuitement.

## Publication GitHub Pages

Fichiers statiques à la racine de la branche main. Dans Settings → Pages, choisir Deploy from a branch, main et /(root). Le fichier .nojekyll évite une transformation par Jekyll.

Aucune compilation ni installation n'est nécessaire. Les chemins relatifs permettent de servir le site dans un sous-dossier GitHub Pages.

## Paiement futur

Une version commerciale exigera un serveur externe pour les commandes, la confirmation du paiement et l'autorisation d'export. Aucune clé secrète ne doit être ajoutée à ce dépôt. GitHub Pages ne fournit pas de serveur de paiement.
